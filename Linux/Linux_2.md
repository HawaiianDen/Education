## 8. Работа с текстом

### Потоки ввода/вывода
- **stdin (0)** — стандартный ввод (клавиатура или файл).
- **stdout (1)** — стандартный вывод (экран).
- **stderr (2)** — стандартный поток ошибок.

### Перенаправление
| Символ  | Назначение                           | Пример                          |
|---------|--------------------------------------|---------------------------------|
| `>`     | Перезаписать вывод в файл            | `ls > files.txt`                |
| `>>`    | Добавить вывод в конец файла         | `echo "hi" >> log.txt`          |
| `<`     | Ввод из файла                        | `wc -l < file.txt`              |
| `2>`    | Перенаправить ошибки в файл          | `ls /no_dir 2> errors.txt`      |
| `&>`    | Объединить stdout и stderr           | `command &> output.log`         |

### Конвейеры (pipes)
- `|` передаёт вывод одной команды на вход другой:
```bash
cat access.log | grep "ERROR" | sort | uniq -c | sort -nr
```

### Текстовые утилиты
| Утилита | Назначение                                        | Пример |
|---------|---------------------------------------------------|---------|
| `grep`  | Поиск текста в файлах                             | `grep -i "error" file.log` |
| `sed`   | Потоковый редактор (замена, удаление строк)       | `sed 's/foo/bar/g' file.txt` |
| `awk`   | Обработка текста по полям                         | `awk '{print $1, $3}' file.txt` |
| `cut`   | Вырезает столбцы                                  | `cut -d: -f1 /etc/passwd` |
| `sort`  | Сортировка                                        | `sort users.txt` |
| `uniq`  | Убирает дубликаты                                 | `uniq -c sorted.txt` |
| `wc`    | Подсчёт строк, слов, символов                     | `wc -l file.txt` |

## 9. Архивация и сжатие

### Основные форматы
- `tar` — объединяет файлы в архив.
- `gzip`, `bzip2`, `xz` — алгоритмы сжатия.
- `zip`/`unzip` — кроссплатформенные архивы.

### Команды
```bash
# Создать архив
 tar -cvf archive.tar dir/

# Распаковать архив
 tar -xvf archive.tar

# Архив + сжатие
 tar -czvf archive.tar.gz dir/
 tar -xvzf archive.tar.gz

# Сжатие
 gzip file.txt      # создаст file.txt.gz
 gunzip file.txt.gz # распаковать

# zip
 zip -r archive.zip dir/
 unzip archive.zip
```

## 10. Управление пакетами

### Debian/Ubuntu (apt)
```bash
sudo apt update                  # обновить список пакетов
sudo apt install nginx           # установка
sudo apt remove nginx            # удаление
sudo apt search nginx            # поиск пакета
sudo apt upgrade                 # обновить систему
```

### RHEL/CentOS (yum/dnf)
```bash
sudo yum install httpd           # установка
sudo yum remove httpd            # удаление
sudo dnf search httpd            # поиск пакета
sudo dnf update                  # обновление системы
```

### Репозитории и ключи GPG
- Репозитории указываются в `/etc/apt/sources.list` или `/etc/yum.repos.d/`.
- Подписи пакетов проверяются через GPG-ключи (`apt-key`, `rpm --import`).

## 11. Дисковое пространство

### Мониторинг
```bash
df -h        # использование дисков в человекочитаемом формате
du -sh *     # размер каталогов в текущей папке
```

### Поиск «тяжелых» файлов
```bash
find / -type f -size +500M 2>/dev/null
```

### Удобный инструмент
```bash
ncdu         # интерактивный просмотр использования диска (нужно установить)
```

## 12. Сетевые утилиты

### Проверка доступности
```bash
ping 8.8.8.8          # проверить соединение
curl -I https://site  # заголовки ответа
wget https://site     # скачать файл
```

### Интерфейсы и IP
```bash
ip addr show          # показать IP-адреса
ifconfig              # старый аналог
```

### Соединения и порты
```bash
ss -tulnp             # список слушающих портов
netstat -tulnp        # (устарело, но встречается)
```

### DNS
```bash
dig example.com       # информация о DNS-записи
nslookup example.com  # старый аналог
```

## 13. История и автодополнение

### История команд
```bash
history        # список команд
!42            # выполнить команду №42
!!             # повторить последнюю
!ls            # повторить последнюю команду, начинающуюся с ls
```

### Поиск в истории
- `Ctrl+R` — поиск по истории (интерактивный).

### Автодополнение
- `Tab` — автодополнение имён файлов и команд.
- Двойной `Tab` — список возможных вариантов.
