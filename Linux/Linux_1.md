## 1. Файловая система и навигация

### Структура FHS (Filesystem Hierarchy Standard)
Стандарт **FHS** определяет расположение директорий и их назначение в Linux. Все пути начинаются с корня `/`.

| Каталог   | Назначение                                                                 |
|-----------|-----------------------------------------------------------------------------|
| `/`       | Корневой каталог, основа всей файловой системы                             |
| `/bin`    | Базовые команды для всех пользователей (`ls`, `cp`, `mv`, `cat`)           |
| `/sbin`   | Системные утилиты для администрирования (`shutdown`, `ifconfig`)           |
| `/boot`   | Файлы загрузчика и ядра Linux                                              |
| `/dev`    | Файлы устройств (диски, терминалы, USB)                                    |
| `/etc`    | Конфигурационные файлы системы и программ                                  |
| `/home`   | Домашние директории пользователей                                          |
| `/lib`    | Системные библиотеки                                                       |
| `/media`  | Точки монтирования для съёмных носителей                                   |
| `/mnt`    | Временные точки монтирования                                               |
| `/opt`    | Дополнительные приложения                                                  |
| `/proc`   | Виртуальная файловая система с информацией о процессах и ядре              |
| `/run`    | Временные данные, PID-файлы, сокеты                                        |
| `/srv`    | Данные сервисов (например, веб-серверов)                                   |
| `/tmp`    | Временные файлы (очищаются при перезапуске)                                |
| `/usr`    | Пользовательские программы и библиотеки                                    |
| `/var`    | Динамичные файлы: логи, базы данных, spool                                 |
| `/root`   | Домашняя директория суперпользователя                                      |

### Пути
- **Абсолютный путь**: от корня (`/home/user/file.txt`).
- **Относительный путь**: от текущего каталога (`../logs`).

### Навигация
```bash
pwd      # показать текущий каталог
ls -la   # список файлов (вкл. скрытые)
cd /etc  # перейти по абсолютному пути
cd ..    # на уровень выше
cd ~     # в домашнюю директорию
file f   # определить тип файла
tree -L 1 # показать дерево каталогов (нужна установка)
```

## 2. Работа с файлами и директориями

| Действие                   | Команда                                   |
|----------------------------|-------------------------------------------|
| Создать файл               | `touch file.txt`                          |
| Создать каталог            | `mkdir dir`                               |
| Создать вложенные каталоги | `mkdir -p dir/subdir`                     |
| Копировать файл            | `cp file1 file2`                          |
| Копировать каталог         | `cp -r dir1 dir2`                         |
| Переместить/переименовать | `mv old.txt new.txt`                      |
| Удалить файл               | `rm file.txt`                             |
| Удалить каталог            | `rm -r dir/` или `rmdir empty_dir`        |

### Просмотр файлов
```bash
cat file.txt        # вывести файл
less file.txt       # постраничный просмотр
head -n 20 file.txt # первые 20 строк
tail -n 20 file.txt # последние 20 строк
tail -f log.txt     # вывод обновлений файла в реальном времени
```

## 3. Права доступа

Каждый файл имеет владельца (user), группу (group) и права для остальных (others).

### Формат прав
- Символы: `r` (чтение=4), `w` (запись=2), `x` (выполнение=1).
- Пример: `rwxr-xr--` → `754`.

### Управление правами
```bash
chmod 755 script.sh     # задать права rwxr-xr-x
chmod u+x script.sh     # добавить право на выполнение для владельца
chown user:group file   # сменить владельца и группу
chgrp group file        # сменить группу
ls -l                   # просмотреть права
```

### Специальные биты
- `umask` — маска по умолчанию.
- sticky bit (`chmod +t dir/`) — запрещает удаление файлов не-владельцам (например, /tmp).
- setuid/setgid — выполнение с правами владельца/группы.

## 4. Поиск файлов и текста

### find
```bash
find /etc -name "nginx*"      # поиск по имени
find /home -size +100M         # файлы >100MB
find /var -mtime -1            # изменены за 1 день
find /tmp -type f -name "*.tmp" -delete # удалить tmp-файлы
```

### locate
```bash
locate passwd
locate --regex '/nginx.*conf$'
```

### grep
```bash
grep "ERROR" /var/log/syslog
grep -RIn "TODO" .
```

### which / whereis
```bash
which python3
whereis ls
```

## 5. Редактирование файлов

### Nano
- `Ctrl+O` — сохранить.
- `Ctrl+X` — выйти.
- `Ctrl+W` — поиск.

### Vim / Neovim
- Режимы: Normal, Insert (`i`), Visual (`v`).
- Основные команды:
  - `:w` — сохранить.
  - `:q` — выйти.
  - `:wq` — сохранить и выйти.
  - `:q!` — выйти без сохранения.
  - `/pattern` — поиск.
  - `:%s/old/new/g` — замена.

## 6. Работа с процессами

### PID и PPID
- PID — идентификатор процесса.
- PPID — родительский процесс.

### Просмотр процессов
```bash
ps aux        # список процессов
top           # мониторинг в реальном времени
htop          # улучшенный top (нужна установка)
```

### Управление процессами
```bash
kill 1234       # завершить процесс (SIGTERM)
kill -9 1234    # принудительно завершить (SIGKILL)
pkill firefox   # завершить процессы по имени
```

### Работа в фоне
```bash
command &    # запуск в фоне
jobs         # фоновые задачи
fg %1        # вернуть в передний план
bg %1        # возобновить в фоне
nohup cmd &  # запуск без прерывания при выходе
```
