## Структура FHS (Filesystem Hierarchy Standard)

Стандарт **FHS** (Filesystem Hierarchy Standard) определяет организацию каталогов и их содержимого в системах Linux и UNIX-подобных ОС. Все файлы и каталоги располагаются внутри корневого каталога `/`, даже если физически находятся на разных устройствах. Этот стандарт помогает программистам и администраторам понимать, где и какие файлы должны находиться, облегчая управление системой.

### Основные каталоги по стандарту FHS:

| Каталог   | Назначение                                                                                             |
|-----------|------------------------------------------------------------------------------------------------------|
| `/`       | Корневой каталог, начало всей иерархии, доступен только суперпользователю для записи                  |
| `/bin`    | Основные утилиты и команды, необходимые для всех пользователей (например, `cat`, `ls`, `cp`)          |
| `/sbin`   | Системные утилиты для администрирования (например, `iptables`, `ifconfig`)                            |
| `/boot`   | Файлы загрузчика и ядра Linux                                                                          |
| `/dev`    | Файлы устройств, обеспечивающие доступ к аппаратуре                                                 |
| `/etc`    | Конфигурационные файлы системы и программ                                                            |
| `/home`   | Домашние директории обычных пользователей                                                             |
| `/lib`    | Библиотеки, необходимые для работы системных программ                                                 |
| `/media`  | Точки монтирования для съемных носителей (USB, CD и т.п.)                                            |
| `/mnt`    | Временные точки монтирования, создаваемые вручную                                                     |
| `/opt`    | Дополнительное программное обеспечение                                                                |
| `/proc`   | Виртуальная файловая система с информацией о процессах и состоянии ядра                               |
| `/run`    | Временные файлы, такие как PID-файлы и сокеты                                                         |
| `/srv`    | Данные сервисов и серверных приложений                                                                |
| `/tmp`    | Временные файлы, удаляемые при перезагрузке                                                          |
| `/usr`    | Вторичная иерархия с программами и библиотеками для пользователей                                     |
| `/var`    | Файлы с изменяемым содержимым (логи, базы данных, кэш и т.д.)                                        |

## Абсолютные и относительные пути

- Абсолютный путь всегда начинается с корня `/` и указывает полный адрес файла или каталога, например:  
  `/home/user/documents`
- Относительный путь указывает расположение файла или каталога относительно текущей директории, например:  
  `../documents` — каталог `documents`, расположенный на уровень выше относительно текущего.

## Краткое пояснение по командам

- `touch` часто используется для быстрой инициализации файлов.
- С `mkdir` можно создавать сразу несколько поддиректорий, перечислив их через пробел.
- Копирование каталога требует флага `-r`, чтобы копировалось содержимое.
- Команда `mv` часто используется для переименования.
- Удаление каталогов с файлами требует осторожности — рекомендуется использовать `-i` для подтверждения.
- Для просмотра больших файлов лучше использовать `less`, так как `cat` выводит всё сразу.
- `head` и `tail` незаменимы для быстрого изучения части файла, особенно журналов.

# Права доступа в Linux

В Linux у каждого файла и каталога есть права доступа, которые определяют, кто и что может с ними делать. Права разделены на три категории:

| Категория    | Описание                                   |
|--------------|--------------------------------------------|
| Пользователь | Владелец файла или каталога               |
| Группа       | Пользователи, принадлежащие к группе файла |
| Другие       | Все остальные пользователи системы         |

---

## Цифровая и символьная нотация прав

Права можно задавать двумя способами: символьным (буквы) и цифровым (числа).

### Символьная нотация

- `r` — право на чтение (read)
- `w` — право на запись (write)
- `x` — право на выполнение (execute)
- `-` — отсутствующее право

Пример:  
`rwxr-xr-x`  

Расшифровка:  
- Владелец может читать, писать и выполнять (rwx)  
- Группа может читать и выполнять (r-x)  
- Другие могут читать и выполнять (r-x)  

### Цифровая нотация

Каждое право — это число:
- `r` = 4
- `w` = 2
- `x` = 1

Суммируем для каждой категории:

| Права       | Владелец | Группа | Другие | Значение | Описание                           |
|-------------|----------|--------|--------|----------|----------------------------------|
| `rwxr-xr-x` | rwx      | r-x    | r-x    | 755      | Владельцу полный доступ, группе и другим — чтение и выполнение |
| `rw-r--r--` | rw-      | r--    | r--    | 644      | Владельцу чтение и запись, остальные только чтение             |
| `rwxrwxrwx` | rwx      | rwx    | rwx    | 777      | Полный доступ для всех (небезопасно)                           |

---

## Команды управления правами доступа

| Команда    | Описание                                  | Пример использования                             |
|------------|-------------------------------------------|------------------------------------------------|
| `chmod`    | Изменяет права доступа                    | `chmod 755 file.sh`<br>`chmod u+x script.sh`  |
| `chown`    | Изменяет владельца и группу               | `chown user:filegroup file.txt`<br>`chown -R user dir/` |
| `chgrp`    | Изменяет только группу                    | `chgrp groupname file.txt`                      |

---

## Понимание вывода `ls -l`

Команда `ls -l` показывает права доступа, владельца, группу и другие атрибуты файлов и директорий:

Пример вывода: `-rwxr-xr-- 1 user group 4096 Sep 25 10:00 script.sh`

- `-rwxr-xr--` — права доступа
- `1` — количество жёстких ссылок
- `user` — владелец файла
- `group` — группа файла
- `4096` — размер в байтах
- `Sep 25 10:00` — дата и время последнего изменения
- `script.sh` — имя файла

---

## Использование `sudo`

- `sudo` позволяет выполнять команды с правами суперпользователя (root).
- Часто используется для изменения прав и владельцев системных файлов, где обычный пользователь не имеет доступа.
  
Пример:
`
sudo chmod 755 /usr/local/bin/script.sh
sudo chown root:root /etc/config.conf
`

# Поиск файлов и текста в Linux

## Основные команды поиска

### Поиск файлов с помощью `find`

`find` — мощная утилита для рекурсивного поиска файлов и директорий с множеством фильтров по имени, размеру, времени, правам и другим параметрам. Работает в реальном времени, обходит все подкаталоги.

#### Примеры использования `find`:

| Цель поиска                          | Команда                                                         | Описание                             |
|------------------------------------|-----------------------------------------------------------------|------------------------------------|
| Поиск по имени (с учетом регистра) | `find /etc -name "nginx*"`                                      | Найдёт все файлы и папки, начинающиеся с "nginx" в каталоге /etc и его подкаталогах |
| Поиск по имени (без учета регистра) | `find /etc -iname "nginx*"`                                     | То же, но без учета регистра         |
| Поиск по расширению                | `find /var/www -type f -name "*.php"`                           | Найдёт все PHP-файлы в каталоге /var/www |
| Поиск по размеру файла             | `find /home -size +100M`                                        | Файлы размером больше 100 мегабайт  |
| Поиск по времени изменения        | `find /tmp -mtime -2`                                           | Файлы, изменённые за последние 2 дня|
| Поиск по владельцу файла           | `find /srv -user www-data`                                      | Файлы, принадлежащие пользователю www-data |
| Поиск по правам доступа            | `find /var -perm 644`                                           | Файлы с правами 644                 |
| Выполнение действия с найденными файлами | `find /tmp -type f -name "*.tmp" -delete`                   | Найдёт и удалит все файлы с расширением *.tmp в /tmp |
| Поиск по содержимому (с `grep`)    | `find /etc -type f -name "*.conf" -exec grep -H "listen" {} \;`| Поиск слова "listen" в конфигурационных файлах |

***

### Быстрый поиск с помощью `locate`

`locate` ищет файлы по имени по базе данных, которая обновляется вручную (`updatedb`) или по расписанию. Очень быстрый, но не всегда актуальный инструмент (не находит очень свежие файлы).

#### Примеры использования `locate`:

| Операция                       | Команда                    | Описание                                       |
|-------------------------------|----------------------------|------------------------------------------------|
| Поиск по имени                 | `locate nginx.conf`         | Быстрый поиск всех путей с файлом nginx.conf   |
| Ограничение количества результатов | `locate -n 10 logrotate`   | Вывести первые 10 совпадений с именем logrotate |
| Поиск с использованием regex  | `locate --regex '/nginx.*conf$'` | Поиск файлов с именем, соответствующим регулярному выражению |

***

### Другие команды поиска

| Команда    | Описание                                                  | Пример                          |
|------------|-----------------------------------------------------------|--------------------------------|
| `grep`     | Поиск текста внутри файлов                                | `grep "ERROR" /var/log/syslog` |
| `which`    | Показывает путь до исполняемого файла команды             | `which python3`                |
| `whereis`  | Показывает местоположение бинарников, исходников и man-страниц | `whereis gcc`                  |

***

## Итоги

- `find` — гибкий и мощный инструмент для полноценного поиска по реальной файловой системе.
- `locate` — быстрый поиск по базе данных, но не всегда актуальный.
- `grep` и другие команды дополняют поиск, расширяя возможности по содержимому и программным файлам.

Эти команды являются обязательными для эффективной работы с Linux-системами и позволяют находить нужные файлы и информацию быстро и точно.

# Редактирование файлов в Linux

## Nano — простой и доступный редактор

- Nano — удобный и интуитивно понятный текстовый редактор, идеальный для новичков.
- Управление осуществляется с помощью сочетаний клавиш, отображаемых внизу экрана (например, `Ctrl+O` для сохранения, `Ctrl+X` для выхода).
- Поддерживает базовые операции: поиск (`Ctrl+W`), замена (`Ctrl+\`), вырезание, копирование и вставку.
- Не требует настроек, запускается быстро и подходит для простого редактирования конфигурационных файлов или заметок.

---

## Vim / Neovim — мощные модальные редакторы

- Vim — мощный текстовый редактор с модальной системой (несколько режимов работы: командный, ввод текста, визуальный).
- Neovim — современный форк Vim с улучшенной архитектурой, расширенной поддержкой плагинов и встроенной поддержкой современных языков программирования.
- Имеют крутое расширяемое окружение и поддерживают работу с большими файлами, макросы, запись скриптов.

### Основные режимы Vim

| Режим          | Назначение                                         | Как войти                        |
|----------------|---------------------------------------------------|---------------------------------|
| Normal (командный) | Выполнение команд редактирования и навигации    | По умолчанию при запуске Vim     |
| Insert (ввод текста) | Ввод и редактирование текста                     | Нажать `i`, `a`, `o`             |
| Visual (выделение)  | Выделение текста для манипуляций (копирование, вырезание) | Нажать `v` или `V`               |
| Command-line      | Ввод команд редактора, например сохранение, выход | Нажать `:` в нормальном режиме   |

### Основные команды Vim

| Действие                     | Команда                              |
|------------------------------|-------------------------------------|
| Войти в режим вставки          | `i`                                 |
| Сохранить файл                | `:w`                                |

# Работа с процессами в Linux

## Понимание PID и родительских процессов

- **PID (Process IDentifier)** — уникальный числовой идентификатор каждого процесса в системе.
- Каждый процесс в Linux имеет родительский процесс, который его запустил. У родительского процесса есть свой PID, известный как **PPID (Parent PID)**.
- Один родительский процесс может порождать несколько дочерних процессов, формируя древовидную структуру процессов.
- Процесс с PID 1 (обычно `init` или `systemd`) является родительским для большинства процессов в системе.

---

## Управление процессами: запуск, остановка, фон/передний план

- Процесс может работать в **переднем плане** (foreground) — взаимодействие с пользователем через терминал.
- Процесс может работать в **фоновом режиме** (background), освобождая терминал, при этом продолжая работу.
- Команды для управления процессами позволяют запускать, останавливать, возобновлять или завершать процессы.

---

## Основные команды для работы с процессами

| Команда | Описание                                                    | Примеры использования                             |
|---------|-------------------------------------------------------------|--------------------------------------------------|
| `ps`    | Показывает текущие запущенные процессы                      | `ps aux` — все процессы с подробной информацией  |
| `top`   | Динамическое отображение процессов с обновлением в реальном времени | Запуск: `top`                                     |
| `htop`  | Улучшенная версия `top` с удобным интерфейсом (требует установки) | Запуск: `htop`                                    |
| `kill`  | Отправляет сигнал процессу для завершения или другого действия | `kill PID` — отправить сигнал SIGTERM процессу с указанным PID |
| `pkill` | Отправляет сигналы процессам по имени                      | `pkill firefox` — завершить все процессы с именем firefox |
| `jobs`  | Показывает запущенные в фоне задания текущего терминала      | `jobs`                                           |
| `bg`    | Возобновить фоновое задание в фоне                         | `bg 1` — возобновить первое фоновое задание      |
| `fg`    | Перевести фоновое задание в передний план                  | `fg 1` — вернуть первое фоновое задание в передний план |

---

## Запуск процессов

- Чтобы запустить процесс в фоне, добавьте `&` в конце команды:`some_command &`
- Для временной приостановки работы процесса используйте сочетание клавиш `Ctrl+Z`.
- Возобновить работу можно командой `fg` (перевести в передний план) или `bg` (продолжить в фоне).

---

## Пример просмотра дерева процессов

- Для просмотра иерархии процессов используется команда `pstree`:`pstree -p`
Здесь отображаются PID родительских и дочерних процессов, что помогает понять структуру.

---

## Итог

Работа с процессами — ключевой навык системного администратора и пользователя Linux. Знание PID, PPID, умение управлять процессами в фоне и на переднем плане, а также использование инструментов мониторинга позволяют эффективно контролировать поведение системы.

# Справка и документация в Linux

## Команда `man` — просмотр справочных страниц

- `man` (manual) открывает руководство по командам, системным вызовам, конфигурационным файлам и другим аспектам системы.
- Пример вызова:`man ls`
Откроется страница с описанием команды `ls`.

### Навигация по странице `man`

- Переход по странице осуществляется с помощью утилиты `less`.
- Основные клавиши:
- `q` — выход из просмотра.
- `j` / стрелка вниз — прокрутка вниз.
- `k` / стрелка вверх — прокрутка вверх.
- `<пробел>` — переход на следующую страницу.
- `/ключевое_слово` — поиск текста внутри страницы.
- `n` — перейти к следующему результату поиска.
- Вверху страницы указывается раздел (секция) документации, например: `ls(1)` — команда из раздела 1.

---

## Секции в `man`

Справочная система Linux разделена на несколько секций:

| Раздел | Тематика                              |
|--------|-------------------------------------|
| 1      | Пользовательские команды             |
| 2      | Системные вызовы (функции ядра)     |
| 3      | Функции библиотек (C API)            |
| 4      | Файлы устройств                      |
| 5      | Форматы файлов и соглашения          |
| 6      | Игры и развлечения                   |
| 7      | Разное (макросы и стандарты)         |
| 8      | Команды системного администрирования |

Для просмотра информации из конкретного раздела указывайте номер, например:`man 5 crontab`

---

## Поиск справочной информации

- Поиск по ключевым словам в названиях и описаниях страниц осуществляется командами:
  - `man -k <ключевое_слово>`  (аналогично `apropos`)
  - `apropos <ключевое_слово>`
  
  Пример:  
`
man -k passwd
apropos network
`

- Команда `whatis` выводит краткое описание указанных команд:  
`
whatis ls
whatis passwd
`

## Быстрая справка и информация

- Большинство команд поддерживают параметр `--help`, который выводит краткую справку:  
`
ls --help
grep --help
`
- Команда `info` — альтернативная система документации с гипертекстовыми возможностями:`info coreutils`
